# Pool de hockey 2026-27

Page mobile du pool : https://pool-a-dave.github.io/2026-27/

Les stats viennent de l'API de la LNH (api.nhle.com) et sont mises à jour toutes les
10 minutes par la tâche GitHub Actions `.github/workflows/maj.yml` (script `maj.py`).

Règles : but = 2, passe = 1, gardien : victoire = 2, défaite en prolongation = 1,
blanchissage = 3, équipe = ses points au classement LNH.
